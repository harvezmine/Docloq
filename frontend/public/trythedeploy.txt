HOW THIS PROVES THE PIPELINE
------------------------------------------------------------

When DEPLOY MARKER changes here and the change is pushed to
the main branch, the self-hosted Gitea Actions runner picks
it up automatically:

  1. git push  ->  main branch (Gitea repo on the VPS)
  2. Gitea Actions runner triggers the workflow
  3. Runner builds the frontend + backend Docker images
  4. Runner redeploys the stack (docker compose up -d)
  5. New frontend goes live behind Traefik (HTTPS via Let's Encrypt)
  6. This URL now shows the new DEPLOY MARKER value

No manual SSH, no manual build. Push = live.
